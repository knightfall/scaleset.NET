# scaleset.NET 0.1.0-alpha.2

This prerelease updates the four .NET 10 NuGet packages:
`Knightfall.ScaleSet.Client`, `Knightfall.ScaleSet.Listener`,
`Knightfall.ScaleSet.Hosting`, and `Knightfall.ScaleSet.Providers.Docker`.

## What changed

- **Runner lifecycle.** Hosting uses a SQLite journal for active operations
  and durable records that prevent completed operations from replaying.
  Reconciliation checks ownership before reclaiming capacity. Graceful
  shutdown can preserve a warm runner once GitHub confirms it belongs to
  the scale set and reports it idle.
- **Docker runner startup.** The provider transfers the just-in-time (JIT)
  configuration at first start through a short-lived handoff on a private
  tmpfs. This keeps the credential out of container creation data and the
  journal. Unprivileged runners now drop Linux capabilities, disallow
  privilege escalation, and disable swap by default.
- **GitHub client and Listener.** This release hardens cancellation, retry and
  deadline handling, authentication token refresh, and Listener recovery.
- **Dependencies and release verification.** This release updates
  Microsoft.Extensions packages and Serilog's OpenTelemetry sink. The manual
  release workflow checks the packaged examples and verifies consumption from
  both NuGet.org and GitHub Packages before announcing the release.

## Upgrade from alpha.1

- **Back up the entire runner state directory with the controller stopped.**
  The new journal imports the previous JSON state into SQLite. Keep the
  database and format marker together. An alpha.1 controller cannot use a
  migrated directory. See the
  [runner state upgrade guide](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.2/docs/implementation/DOCKER-DEPLOYMENT.md#upgrading-runner-state).
- **Update custom Hosting providers.** Implement the new
  `IRunnerProvider.StartAsync(RunnerResource, string?, CancellationToken)`
  signature. Providers that consume JIT at startup opt into
  `RequiresJitConfigurationAtStart`. See the
  [provider compatibility notes](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.2/docs/releases/PUBLISHING.md#compatibility-notes-for-010-alpha2).
- **Check custom Docker images.** The new bootstrap needs a POSIX shell and
  supporting utilities. Review the
  [Docker provider requirements](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.2/src/ScaleSet.Providers.Docker/README.md)
  before upgrading.

## Install and verify

```sh
dotnet add package Knightfall.ScaleSet.Client --version 0.1.0-alpha.2
```

The release assets include the original packages and symbols, the SPDX build
dependency SBOM, and the Sigstore bundles. See the
[artifact verification instructions](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.2/docs/releases/PUBLISHING.md#verify-release-artifacts)
and the [full changes since alpha.1](https://github.com/knightfall/scaleset.NET/compare/v0.1.0-alpha.1...v0.1.0-alpha.2).
