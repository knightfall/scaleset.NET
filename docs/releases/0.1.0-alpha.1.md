# scaleset.NET 0.1.0-alpha.1

This is the first alpha of the .NET 10 libraries for GitHub Actions runner
scale sets. The four packages share version `0.1.0-alpha.1`.

| Package | Contents |
| --- | --- |
| `Knightfall.ScaleSet.Client` | GitHub authentication, administration and runner APIs, and message sessions |
| `Knightfall.ScaleSet.Listener` | Long polling, callbacks, and opt-in checkpointed execution |
| `Knightfall.ScaleSet.Hosting` | Scaling policies, durable runner lifecycle, and provider contracts |
| `Knightfall.ScaleSet.Providers.Docker` | Docker Engine provisioning, recovery, and cleanup |

## What’s included

- GitHub.com and GitHub Enterprise Cloud (`*.ghe.com`). Repository and
  organization targets accept GitHub App or PAT authentication. Enterprise
  targets use a classic PAT with `manage_runners:enterprise`.
- Client behavior aligned to the `actions/scaleset` `716908e5` baseline for
  HTTP/2 keep-alives, strict JSON validation, rate-limit handling, retry
  budgets and deadlines, and bounded response snapshots.
- Opt-in `ScaleSetListenerPump` supports checkpointed delivery, explicit
  deferral, and operation authorization. Existing `ScaleSetListener.RunAsync`
  and session interfaces retain their contracts. A queue refresh must
  preserve the session GUID before Client retries the request. See the
  [checkpointed Listener example](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.1/examples/checkpointed-listener/README.md).
- `ScaleSetClient.DeleteMessageSessionAsync` lets a supervisor retire the
  exact journaled session with administrative credentials after controller
  process loss. A successful response confirms retirement. The replacement
  session starts with a fresh checkpoint identity and cursor.
- A Docker-backed controller you can build from source, with health endpoints,
  durable state, restart reconciliation, and drain-and-preserve shutdown.
  The source includes a Compose quickstart for Linux x64 and arm64 deployments
  with a pinned runner image, collector, and one-job smoke workflow. A .NET 10
  worker example shows how to compose the four packages in your own service.

## Install and verify

```sh
dotnet add package Knightfall.ScaleSet.Client --version 0.1.0-alpha.1
```

See the [usage guide](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.1/docs/usage.md)
for registry configuration and the client example. The release artifacts include
the original package and symbol archives, the build dependency SPDX SBOM, and
Sigstore provenance and SBOM bundles. See the
[verification instructions](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.1/docs/releases/PUBLISHING.md#verify-release-artifacts).

## Alpha scope

Checkpointed execution requires a consumer-supplied fenced store and
replay-safe handler. Same-session continuation uses an already-open session
client. GitHub.com repository-scope canaries verified exact-session retirement
after process loss and exercised acknowledgement-response loss on real jobs
with locally hosted Docker runners. The Listener retains uncertain
acknowledgements for reconciliation. After an ambiguous close, the supervisor
needs independent retirement evidence before replacing the session.
Cross-process reattachment, natural token expiry, and broader target and
authentication scopes require separate qualification.
[Session recovery evidence](https://github.com/knightfall/scaleset.NET/issues/64) ·
[Listener extensibility and AWS handoff](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.1/docs/product/LISTENER-EXTENSIBILITY.md)

Docker is the available runner provider. GHES, custom root CA and mTLS helpers,
private-registry Docker pull authentication, and AWS controller hosting and
runner providers are outside this alpha. See the
[verification record](https://github.com/knightfall/scaleset.NET/blob/v0.1.0-alpha.1/docs/product/VERIFICATION.md)
for test coverage and live-canary status.
